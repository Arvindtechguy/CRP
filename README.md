# CRP - Classroom Portal

A lightweight classroom portal that provides:

- **Timetable** for the class
- **Subject teacher updates** visible to all students
- **Edit access for FA (Faculty Adviser) and CR (Class Representative)**
- **View-only access for students**

## Run

Open `/home/runner/work/CRP/CRP/index.html` in a browser.

## Usage

1. Select your role at the top.
2. As **FA** or **CR**, you can:
   - Edit a day's timetable
   - Post and delete teacher updates
3. As **Student**, you can only view timetable and updates.
